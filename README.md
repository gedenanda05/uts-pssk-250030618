# Festival Kuliner Bali

Landing page sederhana untuk UTS Pengembangan Sistem Sisi Klien.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `festival-kuliner-bali`.
3. Klik dua kali `index.html` atau buka menggunakan Live Server di VS Code.

## File
- `index.html` — struktur halaman semantik dan konten.
- `style.css` — tampilan, Flexbox, CSS Grid, responsive breakpoint, hover, transition, dan animasi.
- `script.js` — menu mobile dan validasi/demo form.

## Catatan
Formulir pada proyek ini hanya simulasi sisi client dan belum mengirim data ke server/database.

## Ketentuan GitHub
Buat repository publik bernama `uts-pssk-250030618`, unggah ketiga file website, lakukan minimal 5 commit terpisah selama pengerjaan, aktifkan GitHub Pages dari branch `main`, lalu salin URL repository dan URL GitHub Pages untuk dikumpulkan.
